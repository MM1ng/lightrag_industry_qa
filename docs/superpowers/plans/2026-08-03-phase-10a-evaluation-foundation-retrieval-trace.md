# Phase 10A Evaluation Foundation & Retrieval Trace Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an immutable admin-only trace for the exact ordinary-query retrieval execution, freeze a provenance-backed 64-question golden set, and produce a real cache-disabled Phase 10A baseline with retrieval metrics and failure diagnosis.

**Architecture:** `LightRAGService.query()` creates an internal typed trace while executing the existing `aquery_data → evidence selection → generation` path. The knowledge-base query adapter enriches and persists that trace best-effort under the ordinary request ID; a separate admin-only GET reads the immutable TTL record without performing retrieval. A standalone HTTP evaluator calls the ordinary endpoint first and the diagnostic endpoint second, then computes deterministic metrics and diagnostics against a frozen real-chunk golden set.

**Tech Stack:** Python 3.11, FastAPI, Pydantic, SQLAlchemy async, Alembic, SQLite local staging, LightRAG 1.5.4, Qdrant client/server 1.13.x, httpx, pytest, Ruff.

## Global Constraints

- Phase 10A must not modify chunking, table handling, TopK, retrieval weights, Rerank, prompts, evidence thresholds, or refusal thresholds.
- The ordinary query response schema and Streamlit client contract must remain unchanged.
- The trace must be generated by the same Query Service execution; the diagnostic GET must never invoke retrieval.
- Missing/invalid admin credentials return 401; SERVICE_API_KEY returns 403; ADMIN_API_KEY can read an unexpired trace.
- Disabled Rerank is represented by `rerank_applied=false`, an empty reranked list, and null reranked rank/score.
- Never persist Secret, Authorization, prompts, vectors, full document bodies, local paths, or unsanitized endpoints.
- Trace-write failure must not fail an ordinary query and must increment an observable failure counter.
- The golden set must contain 64 real, provenance-backed records split 36 development / 16 validation / 12 holdout.
- Phase 10A baseline runs with LLM cache disabled; holdout is not used for tuning.
- Do not create a Tag, package an RC, deploy production, introduce LangGraph, or begin Phase 10B–10D.
- Preserve `phase3-uncommitted-backup.patch` unchanged.
