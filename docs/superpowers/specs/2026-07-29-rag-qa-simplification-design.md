# 单一 RAG 问答应用收敛设计

**日期：** 2026-07-29
**状态：** 已确认，待实施

## 目标

将仓库收敛为面向工业手册的单一知识问答应用。用户提交问题后，系统检索已摄取的文档、生成仅基于证据的回答，并返回文档名、物理页码和块 ID。

## 保留的主链路

```text
Streamlit 聊天界面 -> FastAPI 问答接口 -> industrial_rag 服务 -> LightRAG -> 回答与引用
```

- `industrial_rag` 继续负责文档解析、按页分块、LightRAG 导入和检索、引用提取。
- FastAPI 只暴露健康检查、受控摄取和 `POST /v1/query` 问答接口。
- Streamlit 只调用问答 API 并显示回答、状态和可验证引用。
- 无充分检索证据时，接口返回明确的依据不足回答，不臆测内容或伪造引用。

## 明确移除的范围

从主代码、默认依赖、测试和项目文档中移除以下不属于问答助手的能力：

- LangGraph、Agent 编排和多 Agent 路由。
- 传感器数据处理、故障诊断、合成案例分析。
- 工单草稿、人工审批、SQLite 审计和相关持久化工作流。
- 只为以上能力存在的领域模型、工具、API 契约、测试及设计/实施计划。
- Ragas、Langfuse 及其他当前未用于问答主链路的新增集成不进入第一版。

删除不会抹去历史：所有已跟踪文件仍可通过 Git 历史追溯；仓库不再维护额外的 `legacy` 副本。

## API 与界面边界

- 问答请求只接受非空问题和可选的有限对话历史。
- 问答响应包含请求 ID、状态、回答、引用、声明与延迟；不返回模型密钥、内部异常、隐藏推理或未验证的页码。
- 摄取路径继续只接受受控的本地文档来源，不能成为任意 URL 或路径读取入口。
- Streamlit 不直接导入或调用 LightRAG、模型 SDK、索引目录或存储层。

## 错误与质量约束

- 上游不可用、超时、索引未就绪和请求无效都映射为稳定的公开错误码与安全消息。
- 所有引用必须能关联到实际解析块，至少包含文档名、页码和块 ID。
- 默认测试保持离线，不要求真实模型密钥；真实 LightRAG 调用留在显式 Smoke 命令中。

## 验收标准

1. 默认依赖和运行入口不再包含 LangGraph、多 Agent、传感器、工单或审批组件。
2. README 只描述安装、文档解析、摄取、FastAPI、Streamlit、测试和问答运行方式。
3. 默认测试只覆盖问答主链路的解析、引用、服务契约、API 客户端和界面状态。
4. `POST /v1/query` 能在索引就绪时返回带可验证引用的问答结果，并在证据不足或服务失败时安全降级。
